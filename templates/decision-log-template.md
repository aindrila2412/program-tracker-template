# Decision Log (template)

> TEMPLATE. Fill in for your own program. Rows below are blank placeholders.

A short running record of decisions, so people can find out what was decided, who decided it and why, without digging
through old threads. Add a row when a decision is made, not when it is first discussed. Link to the RAID log (for
example `R-001`) or to an issue when a decision came out of one.

## Decisions

| ID | Date | Decision | Decided by | Why | Alternatives considered | Related RAID / issue | Status |
|---|---|---|---|---|---|---|---|
| DEC-001 | YYYY-MM-DD | | | | | | |

## Status values

- **Proposed**: written down but not yet agreed
- **Agreed**: the decision stands
- **Superseded**: replaced by a later decision (note the new ID in the Why column)
- **Reversed**: dropped without a replacement (say why)

## Tips

- Keep the decision to one sentence. Put detail in a linked page or issue.
- Don't edit old rows to change what was decided. Add a new row and mark the old one Superseded.
- Review the log at each weekly status and pull any open asks into the "Decisions and asks" table.
